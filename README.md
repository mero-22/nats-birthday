# For Natalie ♡ — Interactive Birthday Website

Features: soft-pink birthday letter, scrapbook gallery, heart-tapping game (surprise at 100 taps), quiz with an answer-based personalized conclusion, and final surprise.

## Customize
Edit the `CONFIG` object at the top of `script.js`: name, letter, surprise messages, heart reward message, photos, and questions. Each question option has a `trait` sentence; the selected traits are combined into the final conclusion.

### Pinterest photos
Pinterest pin-page links are not direct image links. Save images you have permission to use into a folder named `images` beside `index.html`, then use paths like `images/photo1.jpg` in `CONFIG.photos`.

## Publish free with GitHub Pages
1. Create a public GitHub repository. 2. Upload all four files and your `images` folder. 3. Open Settings → Pages. 4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save. 5. Wait for the public Pages link.
